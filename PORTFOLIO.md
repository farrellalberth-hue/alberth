# Alberth Farrell — Intelligence, by Design

An independent portfolio for Alberth Farrell. Luxury editorial black/crimson design with a responsive layout, an animated network hero, AI specialist explorer, and interactive knowledge atlas.

## Production
https://alberth-portfolio-one.vercel.app/

## Source of information
Public-facing summaries are derived from Alberth's private **Alberth-Second-Brain** documentation (curated owner-approved context and current nine-role directory, October 2026). The Second Brain itself is **not shipped** to the website.

## Important boundaries
- AI specialist descriptions express architectural responsibilities, not blanket production verification.
- Study areas are not represented as formal degrees, certification, mastery, or professional employment.
- Illustrative chart is **not** live market data.
- The typographic portrait is a placeholder until a genuine user-approved image is provided.
- Private financial and business records, credentials, and internal GitHub source code are never embedded.
- Instagram and TikTok references are not reproduced from unverified external media.

## Editing
The website is one portable `index.html` and needs no Node.js or build process. Update HTML/CSS/JS and push to the `main` branch; Vercel can build the static output directly. For local preview, open `index.html` in Chrome or run `python -m http.server 8000` and visit `http://localhost:8000`.

## Accessibility
Supports mobile layouts, keyboard navigation, reduced motion, aria live updates, and semantic page sections.
